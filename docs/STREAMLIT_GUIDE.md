# Streamlit 用户界面使用指南

## 🚀 快速启动

### 方式一：一键演示启动（推荐）

```bash
# 在项目根目录运行
bash scripts/start_demo.sh
```

这将自动：
- 检查Python环境和依赖
- 创建示例数据
- 启动完整的Streamlit界面
- 在浏览器中打开 http://localhost:8501

### 方式二：使用启动脚本

```bash
# 启动完整界面（默认）
bash scripts/run_streamlit.sh

# 或者选择特定模式
bash scripts/run_streamlit.sh
# 然后选择：1=完整界面，2=极简界面，3=知识图谱
```

### 方式三：直接启动

```bash
# 安装依赖
pip install streamlit streamlit-agraph plotly pandas

# 启动完整界面
streamlit run src/app/streamlit_ui.py

# 启动极简界面
streamlit run src/app/simple_ui.py
```

## 📱 界面功能

### 1. 完整界面 (`streamlit_ui.py`)

**🔍 主要功能页面**：

#### 📥 数据获取与管理
- **文件上传**：支持PDF、Word、Excel、CSV、TXT、JSON等格式
- **URL抓取**：批量抓取网页内容并自动处理
- **在线输入**：直接输入或粘贴文本
- **文档管理**：查看、删除、导出已处理的文档

#### 🔍 跨语言检索
- **多语言查询**：支持中文、法语、英语
- **智能搜索**：结合密集检索、BM25、知识图谱
- **结果展示**：分页显示、相关度评分、知识图谱路径
- **导出功能**：CSV格式导出搜索结果

#### 🕸️ 知识图谱
- **交互式图谱**：节点拖拽、缩放、搜索
- **统计分析**：节点类型分布、语言覆盖等
- **路径查找**：查找概念之间的关联路径
- **数据导出**：PNG、SVG、JSON等格式

#### 🎓 学习支持
- **概念选择器**：浏览和学习不同概念
- **练习生成**：基于知识图谱的智能练习题
- **进度追踪**：个人学习记录和掌握度分析
- **路径推荐**：个性化学习路径规划

#### ⚙️ 系统设置
- **模型参数**：检索模型配置和权重调节
- **外部服务**：Neo4j、Elasticsearch等服务配置
- **存储管理**：缓存清理、存储统计

### 2. 极简界面 (`simple_ui.py`)

**🎯 特点**：
- 单页面设计，操作简单
- 响应式布局，移动端友好
- 核心搜索功能，快速上手

**功能**：
- 简化搜索框
- 多语言结果展示
- 快速统计概览
- 使用帮助和FAQ

## 📁 文件处理支持

### 支持的文件格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| PDF文档 | `.pdf` | 支持文本提取，保留格式 |
| Word文档 | `.docx`, `.doc` | 提取文本、表格内容 |
| Excel表格 | `.xlsx`, `.xls` | 转换为文本格式 |
| CSV文件 | `.csv` | 自动检测编码 |
| 文本文件 | `.txt` | 支持多种编码 |
| JSON文件 | `.json`, `.jsonl` | 结构化数据提取 |

### 处理功能

- ✅ **自动语言检测**：识别文档语言（中法英）
- ✅ **文本规范化**：清理、标准化文本内容
- ✅ **质量评分**：基于长度、重复性等因素
- ✅ **重复检测**：基于文件校验和的重复检测
- ✅ **批量处理**：多文件并行处理
- ✅ **进度显示**：实时显示处理进度

## 🔍 搜索功能

### 搜索类型

1. **综合搜索**：结合多种检索方法
2. **知识图谱搜索**：基于知识图谱的语义搜索
3. **纯文本搜索**：基于文本内容的传统搜索

### 搜索技巧

- **关键词搜索**：输入核心概念，如"虚拟式"、"语法"
- **短语搜索**：使用完整短语，如"法语虚拟式用法"
- **跨语言搜索**：用一种语言搜索另一种语言的内容
- **自动检测**：系统自动识别查询语言

### 结果展示

- **相关性评分**：显示匹配度分数
- **语言标识**：用国旗标识内容语言
- **内容预览**：显示文档内容摘要
- **知识路径**：展示知识图谱中的关联路径

## 🕸️ 知识图谱可视化

### 交互功能

- **节点操作**：拖拽、点击查看详情
- **缩放平移**：鼠标滚轮缩放，拖拽平移
- **搜索过滤**：按类型、语言过滤节点
- **路径高亮**：显示节点间的关联路径

### 统计分析

- **节点分布**：实体类型、语言分布饼图
- **关系统计**：关系类型柱状图
- **度分布**：节点连接度直方图
- **连通性**：图谱连通组件分析

## ⚙️ 配置选项

### 环境变量

```bash
# Streamlit配置
STREAMLIT_SERVER_PORT=8501          # 服务器端口
STREAMLIT_SERVER_ADDRESS=0.0.0.0     # 服务器地址

# 项目配置
PYTHONPATH=/path/to/kgclir          # Python路径
DATA_STORAGE_PATH=data/uploads      # 数据存储路径
```

### 模型参数

- **密集检索模型**：选择sentence-transformers模型
- **检索权重**：调节不同检索方法的权重
- **批处理大小**：影响处理速度和内存使用

## 🔧 故障排除

### 常见问题

**Q: 启动时提示模块导入错误**
```bash
# 解决方案：设置PYTHONPATH
export PYTHONPATH="$(pwd):${PYTHONPATH}"
streamlit run src/app/streamlit_ui.py
```

**Q: 文件上传失败**
- 检查文件格式是否支持
- 确认文件大小不超过限制（默认200MB）
- 检查文件是否损坏

**Q: 搜索结果为空**
- 检查是否已上传文档
- 尝试使用更精确的关键词
- 确认语言设置正确

**Q: 知识图谱不显示**
- 检查是否已加载知识图谱文件
- 确认graph相关依赖已安装
- 尝试使用示例数据

### 日志查看

```bash
# 查看Streamlit日志
tail -f logs/streamlit.log

# 查看应用日志
tail -f logs/kgclir.log
```

### 性能优化

- **内存不足**：减小批处理大小，减少并发数
- **处理速度慢**：使用GPU加速，优化模型参数
- **界面卡顿**：减少显示结果数量，启用分页
